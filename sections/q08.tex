\begin{frame}{Q8 — porting order}
  \begin{enumerate}\setlength\itemsep{3pt}
    \item KV pool layout \texttt{[2, num\_blocks, H, 1, block\_size, D]}; \texttt{block\_size} $=$ partition.
    \item Fixed-shape prefill / decode graph interfaces.
    \item RBLN \texttt{AttentionBackend} — translate forward metadata into the fixed tensors.
    \item Compile the covering set $+$ artifact cache.
    \item Host radix layer — align matched prefixes to sub-block $=$ chunk size.
    \item KV write / reuse — scatter $+$ scheduled copy op for a partial hit.
    \item Absolute-position RoPE; scheduler guard; step-fenced eviction.
    \item TP (collectives in-graph); correctness $+$ boundary validation; telemetry.
  \end{enumerate}
\end{frame}
