\begin{frame}{Q5 — 컴파일 스펙트럼별 강제사항}
  \hd{Reframe} Not about compilation — about what the stack may assume about shapes, and what a miss costs.
  \begin{itemize}\setlength\itemsep{3pt}
    \item \textbf{Eager} — total freedom; host is the bottleneck. C++ hot path, overlap.
    \item \textbf{JIT $+$ cache} — first hit compiles; soft bucketing; versioned cache; SLO guard.
    \item \textbf{Capture / replay} — fixed shapes \emph{and} addresses; no control flow in the region.
    \item \textbf{Strict AOT} — shape set frozen at build; uncompiled shape cannot run
          $\Rightarrow$ scheduler guarantees legal shapes; every dynamic path $=$ fixed compute $+$ host post-proc.
  \end{itemize}
  \hd{My environments}
  \begin{itemize}
    \item Gaudi $=$ capture/replay $+$ JIT fallback — precompile the covering set (a miss stalls the engine).
    \item Battlemage $=$ eager, forced by oneCCL/SYCL not composing (no multi-card).
  \end{itemize}
\end{frame}
