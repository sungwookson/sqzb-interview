  \hd{How SGLang differs}
  \begin{itemize}
    \item \textbf{Overlap scheduler} — build the next batch on CPU while the current runs on device.
    \item Radix / cache-aware admission; FSM $+$ jump-forward in the scheduler.
    \item vLLM v1: separate EngineCore, chunked prefill by default.
  \end{itemize}
  \hd{Importance for RBLN — the top TPOT lever}
  \begin{itemize}
    \item Decode device step is short and fixed $\Rightarrow$ host fraction dominates.
    \item host $\ge$ device $\Rightarrow$ TPOT set by the scheduler loop, not the chip.
    \item vllm-rbln is host-heavy today (pinned \texttt{\_to\_list}, per-step masks, Python-loop KV copies, async off).
    \item Porting the overlap scheduler $=$ \textbf{greenfield}. Caveat: TTFT is device-bound.
  \end{itemize}
