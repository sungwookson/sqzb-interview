\begin{frame}{전제 — vllm-rbln에서 읽어낸 RBLN 스택}
  \small
  \begin{itemize}
    \item \textbf{완전 AOT.} 런타임 컴파일 / eager fallback 없음 — 미준비 shape은 실행 불가(경고만).
    \item \textbf{두 경로.} optimum-rbln \texttt{.rbln} 아티팩트 \;/\; \texttt{torch.compile(dynamic=False)} + rebel backend.
    \item \textbf{Prefill 단독 실행}(batch $=1$), \textbf{decode batch 차원만 버킷팅}. seq length는 버킷 안 함 — 고정 \texttt{max\_model\_len} 그래프 + host mask.
    \item \textbf{KV block $=$ attention partition} (1--4K tok) $\Rightarrow$ sub-block prefix caching 별도 계층; prefix hit 시 matched KV를 새 블록에 \emph{복사}(동기·전 레이어·forward 전).
    \item \textbf{TP는 그래프에 컴파일}(per-op NCCL 없음). \textbf{overlap scheduler 없음}(async 비활성).
  \end{itemize}
  \vspace{0.4em}
  \begin{alertblock}{한 줄}
    RBLN은 strict-AOT — 미준비 shape에 대한 런타임 탈출구가 없다. 나머지 모든 설계가 여기서 파생된다.
  \end{alertblock}
\end{frame}
